# Perguntas frequentes

Respostas curtas para as dúvidas mais comuns sobre o app, os dados e o projeto.

## O app é gratuito?

Sim, e todas as funcionalidades são abertas a todos. O código é aberto sob a licença GPL-3.0: qualquer pessoa pode ler, conferir, adaptar e contribuir.

## Funciona no iPhone e no computador?

O app roda no Android, no iOS e no navegador. Os dados de cada aparelho são independentes: para levar as fichas de um para outro, use o backup.

## Preciso de internet?

Não. Só para salvar o backup na nuvem, se você escolher o Google Drive, ou para abrir links externos.

## Os resultados são confiáveis?

Cada fórmula foi conferida na fonte primária, e o exemplo publicado de cada método é testado automaticamente nas duas implementações do projeto. Mesmo assim, as calculadoras apoiam e não substituem o julgamento clínico. Veja **Mais → Referências e auditoria**.

## Encontrei um erro. Como aviso?

Em **Mais → Relatar um problema**. O app monta o relato com informações técnicas (versão, sistema, erros registrados no aparelho) e abre o GitHub já preenchido. Nada é enviado sem você ver. Não inclua dados de pacientes.

## Como sei o que mudou numa versão?

Em **Mais → Sobre o OpenNutri BR → Novidades**.

## Como citar o app num trabalho?

Em **Mais → Sobre o OpenNutri BR → Como citar**.

## O app fica com os dados dos meus pacientes?

Não. Os dados ficam só no seu aparelho; ninguém mais tem acesso. Veja [Privacidade e LGPD](07-privacidade.md).
